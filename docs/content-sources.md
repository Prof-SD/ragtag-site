# Content and artwork sources

Game facts were checked against the local implementation and release records on 22 November 2026:

- `README.md`, `Documentation/Release-Readiness.md` and `Documentation/Playtest-Build22/Review.md` in the game project.
- `Documentation/Release/Product-Configuration.json` and draft privacy/support/storefront documents. Stale Help terminology was corrected in website copy using build 22's current Toss/context controls. The proposed development price was not used publicly.
- `PlokGame/Rendering/PlushCatalog.swift`, game artwork, and native capture provenance. Exact copied source paths and SHA-256 hashes are in `asset-provenance.json`.
- Original outline lettering paths were adapted from `Scripts/DrawHeadingArtwork.swift`; website heading SVGs are generated by `src/lettering.mjs` with no font dependencies.

- Vercel hosting privacy: https://vercel.com/legal/privacy-notice
- Apple privacy: https://www.apple.com/legal/privacy/

No new AI images were needed for this website. Existing original game illustrations and screenshots were mechanically resized, EXIF-oriented and transcoded to WebP. No screenshots were represented as a new gameplay recording. No testimonials, awards, download counts, commercial clearance or live App Store availability were invented.
